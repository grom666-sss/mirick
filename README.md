# Mirick Menu

Чистое визуальное меню для **GTA San Andreas (DirectX 9, 32-bit)** в стиле указанного пользователем интерфейса. В проекте нет читов, игровых модификаций, сетевого обхода или обращения к памяти GTA: меню рисует только собственный UI.

## Возможности

Меню переписано в стилистике интерфейса [ForkHack](https://github.com/gabrik1337/ForkHack):

- окно 720×520 с отдельной шапкой, боковой колонкой вкладок и областью контента;
- пять вкладок с векторными иконками, подсветкой при наведении и акцентной полосой активной вкладки;
- подвкладки-пилюли с анимированным подчёркиванием акцентным цветом;
- собственные виджеты: переключатель-тумблер, слайдер с градиентной заливкой и «ручкой», выпадающий список, кнопка, выбор цвета, поле горячей клавиши;
- плавные анимации появления, смены вкладок и наведения (скорость настраивается);
- перетаскивание окна за шапку, тень и рамка, масштаб интерфейса 0.8×–1.4×;
- два языка интерфейса (русский/английский) и настраиваемая клавиша открытия (по умолчанию **Insert**).

Все настройки меню — демонстрационные и влияют только на сам интерфейс.

## Сборка

Требуются Windows, Visual Studio 2022 с компонентом **Desktop development with C++**, CMake и Git.

```bat
cmake -S . -B build -A Win32
cmake --build build --config Release
```

Результат сборки — только `build/Release/MirickMenu.dll`.

Сборка также выполняется автоматически в GitHub Actions (workflow «Build Windows DLL»): готовая 32-битная `MirickMenu.dll` публикуется в релизе
[mirick-menu-latest](https://github.com/grom666-sss/mirick/releases/tag/mirick-menu-latest).

## Установка

Загрузите `MirickMenu.dll` с помощью совместимого легального DLL-загрузчика модов, следуя его инструкции. После запуска игры нажмите **Insert**.

Проект рассчитан на классическую 32-битную DirectX 9 версию игры. Настройки в текущей версии демонстрационные и не изменяют игровой процесс.

## Зависимости

CMake автоматически загружает Dear ImGui 1.91.9b и MinHook 1.3.4. Их лицензии находятся в соответствующих исходных репозиториях.
